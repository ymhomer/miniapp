Version notes

Changes in this revision.

Cleaner default state

Fresh data starts empty, except for a neutral Work Inbox project so new records have a place to belong.

Corrected check-in missed logic

A check-in only counts as missed from its effective start date onward, so creating a template today will not create historical missed records.

Frequency-specific settings

Daily and weekdays use simple schedules, weekly shows weekday selection, and monthly shows the day-of-month setting.
